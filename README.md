# 🐍 Learn Python — Interactive Learning Path

> **Created by Somasundar** 🚀

Welcome to your Python learning journey! This project contains **15 structured lessons** that take you from absolute beginner to confident Python programmer.

## 📚 How to Use

### Option 1: Interactive Web Dashboard
Open `dashboard/index.html` in your browser for a beautiful, interactive lesson viewer with progress tracking.

### Option 2: Run Lessons Directly
Each lesson is a standalone `.py` file. Run them in order:

```bash
cd lessons
python 01_hello_world.py
python 02_variables_and_types.py
# ... and so on
```

### Option 3: Practice with Exercises
Each lesson has a matching exercise file in the `exercises/` folder:

```bash
cd exercises
python ex_01_hello_world.py
```
